# 타자 훈련소

중학교 1학년 정보 수업에서 매시간 10분씩 쓰는 한글·영문 타자 연습 웹앱입니다.
자리연습으로 기본기를 익히고, 승급 테스트를 통과하면 배틀 모드가 열립니다.

## 기능

| 구분 | 내용 |
|---|---|
| 자리연습 | 한글 8단계 + 기호 2단계 + 영문 7단계. 가상 키보드와 손 실루엣으로 눌러야 할 손가락을 보여 줍니다 |
| 승급 테스트 | 50문항, 90점 이상이면 다음 단계로 승급 |
| 낱말·단문·장문 | 과목별 낱말(뜻풀이 포함)과 문장, 긴 글 연습 |
| 뜻 맞추기 퀴즈 | 뜻풀이를 보고 맞는 낱말을 직접 쳐서 답하는 어휘 퀴즈 |
| 수행평가 | 정해진 시간 동안 긴 글을 치고 최종 타수로 A~E 등급을 받는 평가(교사가 열고 닫음) |
| 배틀 | 자리연습을 마친 학생끼리 최대 16명, 같은 계급끼리 겨루는 낱말 게임. 낱말이 사방에서 날아오고 인원이 많을수록 더 많이 쏟아집니다. 경기 시간은 방장이 1~5분 중에 고릅니다(기본 2분) |
| 배틀 특수 낱말 | ⚡빠름 +1 · 👻깜빡(보였다 안 보였다) +2 · 🌀흔들 +1 · ★황금 2배 |
| 배틀 협동 낱말 | 🤝 표시 낱말은 참가자 모두가 각자 쳐야 합니다. 다 같이 성공하면 모두 그 낱말 점수의 2~4배(천천히 오는 낱말 2배, 빠를수록 3·4배) |
| 배틀 피버·안개·거꾸로 | 경기 중 🔥 피버 타임 10초(점수 2배, 낱말 폭주), 🌫️ 안개(가운데가 가려짐), 🙃 거꾸로(낱말이 뒤집힘) 구간이 나옵니다 |
| 배틀 역전 찬스 | 하위권 학생에게만 보이는 🚀 고득점 낱말(+4) |
| 배틀 뜻 낱말 | 📖 뜻풀이가 떠다니고 알맞은 낱말을 쳐야 득점(+2) |
| 배틀 팀전 | 방장이 대기실에서 개인전·팀전(홍팀·청팀)을 고릅니다. Realtime Database 규칙 배포 필요 |
| 학급 배틀 | 선생님이 수업 설정에서 켜면 같은 반 학생이 모두 한 방(최대 40명)에 들어가 함께 칩니다. 반 총점과 참여 학생이 기록되어 홈 화면에 날짜·총점·참여 학생 이름이 보이고, 반별 최고 총점으로 겨룹니다. 경기 시간은 선생님이 고릅니다(기본 5분). 규칙 배포 필요 |
| 배틀 칭호 | 결과 화면에서 속사포·협동왕·막판 스퍼트 등 칭호를 줍니다 |
| 배틀 파워게이지 | 오타 없이 연속 20개를 얻으면 다른 참가자 점수의 절반을 한꺼번에 가져옵니다 |
| 배틀 배경음 | 경기 중 배경음(소리를 켠 경우에만, 경기 화면에서 끌 수 있음) |
| 배틀 멈추기 | 선생님이 정한 문장을 친 학생만 몇 초 동안 입력할 수 있고 나머지는 멈춥니다(한 판에 한 사람 한 번, 문장·시간은 수업 설정에서) |
| 바른 말 | 배틀에서 욕설을 치면 경고와 함께 그 학생의 입력을 잠시 막습니다(시간·추가 낱말은 수업 설정에서) |
| 컴퓨터 대결 | 친구가 없을 때 컴퓨터 3명(새내기·맞수·고수)과 겨루는 연습 배틀. 내 최고 타수·계급 포인트에 맞춰 컴퓨터 속도를 정하고, 이기면 빨라지고 지면 느려집니다(RP 절반) |
| 계급 | 훈련병 → 이등병 → 일병 → 상병 → 병장 → 예비역 |
| 순위 | 배틀·타수·퀴즈·성실 순위 |
| 선생님 모드 | 학생 추가·삭제·일괄 등록, PIN 초기화, 학습 현황, 수업 설정(배틀 허용·임시 공개, 연습·배틀에 낼 과목·단원 고르기 등), 콘텐츠 올리기 |
| 키보드 선택 | 데스크톱 / 노트북 / 서피스 고3 |
| 선생님 회원 | 선생님은 첫 화면의 [선생님] 탭에서 성함과 PIN 으로 가입 신청하고, 관리자가 학생 관리에서 '선생님'에 체크하면 입장할 수 있습니다(관리자 권한은 없음). Firestore 규칙 배포 필요 |
| 학생이름 외우기 | 선생님 회원 전용. 나이스 사진명렬표 엑셀(반별·학년별 여러 개)을 고르면 사진과 이름이 위에서 떨어지고, 이름을 쳐서 맞추며 외웁니다. 사진과 이름은 그 컴퓨터의 브라우저에만 저장되고 서버로 보내지 않습니다 |

## 우리 학교에 설치하기 (구글 계정만 있으면 됩니다)

[![Open in Cloud Shell](https://gstatic.com/cloudssh/images/open-btn.svg)](https://shell.cloud.google.com/cloudshell/editor?cloudshell_git_repo=https://github.com/Parkdongbae/taja-camp&cloudshell_tutorial=docs/SETUP.md)

1. 위 버튼을 눌러 구글의 무료 웹 터미널(Cloud Shell)을 엽니다.
2. 터미널에 `npm run setup` 한 줄을 실행합니다.
3. 끝나면 나오는 주소(`https://taja-xxxxxxxx.web.app`)를 열고 **선생님 모드**에서 첫 계정을 만듭니다.

프로젝트 만들기, 데이터베이스, 로그인 방식, 보안 규칙, 사이트 올리기까지 자동으로 합니다. 무료(Firebase Spark 요금제)이고 5~10분쯤 걸립니다.
자세한 안내와 문제 해결은 [docs/SETUP.md](docs/SETUP.md)를 보세요.

## 실행

```bash
npm install
npm run dev
```

`.env` 가 없으면 **데모 모드**로 동작합니다(이 브라우저에만 저장, 탭 여러 개로 배틀 시험 가능).
데모 모드에서는 학번 `1101`~`1106` 이 미리 등록되어 있고, "처음 접속"을 선택해 PIN 을 만들면 됩니다.

```bash
npm test         # 타자 엔진 단위 테스트
npm run build    # 타입 검사 + 빌드
```

## Firebase 연결 (직접 설정할 때)

위 자동 설치를 쓰지 않고 손으로 연결하는 방법입니다.

1. Firebase 프로젝트에서 Authentication(익명, 이메일/비밀번호), Firestore, Realtime Database 를 사용 설정합니다.
2. `.env.example` 을 `.env` 로 복사하고 웹 앱 설정값을 채웁니다.
3. 보안 규칙을 배포합니다.

```bash
npx firebase-tools deploy --only firestore,database --project <프로젝트 ID>
```

4. 배포 주소를 Authentication > 설정 > 승인된 도메인에 추가합니다.
5. 앱의 `선생님 모드`에서 가장 먼저 가입한 계정이 관리자가 됩니다. 관리자는 다른 선생님의 이메일을 초대할 수 있습니다.

Vercel 에 배포할 때는 `.env` 의 다섯 값(`VITE_FIREBASE_*`)을 프로젝트 환경 변수로 등록합니다.

## 학생 로그인

학번 4자리(학년 1 + 반 1 + 번호 2, 예: `1315`) + 이름 + PIN 4자리.
선생님이 명단을 등록하면, 학생은 첫 접속 때 PIN 을 직접 정합니다. PIN 을 잊으면 선생님 모드에서 초기화합니다.

## 콘텐츠

앱에는 기초 낱말·문장과 국어·영어·수학·사회·과학 과목별 낱말(뜻풀이 포함)·문장·글이 내장되어 있어, 설치하자마자 바로 쓸 수 있습니다(모두 새로 쓴 내용). 학교 수업에 맞춘 콘텐츠를 더 넣으려면 선생님 모드의 `콘텐츠` 탭에서
JSON 파일로 올리며, 로그인한 학생만 볼 수 있습니다.

```json
{
  "words":     [{ "id": "w-001", "text": "낱말", "meaning": "뜻풀이", "lang": "ko", "subject": "korean", "unit": "단원", "level": 1 }],
  "sentences": [{ "id": "s-001", "text": "문장입니다.", "lang": "ko", "subject": "korean", "unit": "단원", "level": 1 }],
  "passages":  [{ "id": "p-001", "title": "제목", "text": "긴 글...", "lang": "ko", "subject": "korean", "unit": "단원", "level": 2 }]
}
```

`subject` 는 `korean` `english` `math` `science` `social` 중 하나, `lang` 은 `ko` 또는 `en` 입니다.

## 알아 둘 점

- 서버 없이 보안 규칙만으로 권한을 관리합니다. 4자리 PIN 은 수업용 수준의 보호입니다.
- 소리는 기본으로 꺼져 있습니다.
