# 타자 훈련소

중학교 1학년 정보 수업에서 매시간 10분씩 쓰는 한글·영문 타자 연습 웹앱입니다.
자리연습으로 기본기를 익히고, 승급 테스트를 통과하면 배틀 모드가 열립니다.

## 기능

| 구분 | 내용 |
|---|---|
| 자리연습 | 한글 8단계 + 기호 2단계 + 영문 7단계. 가상 키보드와 손 실루엣으로 눌러야 할 손가락을 보여 줍니다 |
| 승급 테스트 | 50문항, 90점 이상이면 다음 단계로 승급 |
| 낱말·단문·장문 | 과목별 낱말(뜻풀이 포함)과 문장, 긴 글 연습 |
| 뜻 맞추기 퀴즈 | 뜻풀이를 보고 맞는 낱말을 직접 쳐서 답하는 어휘 퀴즈 |
| 수행평가 | 정해진 시간 동안 긴 글을 치고 최종 타수로 A~E 등급을 받는 평가(교사가 열고 닫음) |
| 배틀 | 자리연습을 마친 학생끼리 최대 16명, 같은 계급끼리 겨루는 낱말 낙하 게임 |
| 컴퓨터 대결 | 친구가 없을 때 컴퓨터 3명(새내기·맞수·고수)과 겨루는 연습 배틀. 내 최고 타수·계급 포인트에 맞춰 컴퓨터 속도를 정하고, 이기면 빨라지고 지면 느려집니다(RP 절반) |
| 계급 | 훈련병 → 이등병 → 일병 → 상병 → 병장 → 예비역 |
| 순위 | 배틀·타수·퀴즈·성실 순위 |
| 선생님 모드 | 학생 추가·삭제·일괄 등록, PIN 초기화, 학습 현황, 수업 설정(배틀 허용·임시 공개 등), 콘텐츠 올리기 |
| 키보드 선택 | 데스크톱 / 노트북 / 서피스 고3 |

## 실행

```bash
npm install
npm run dev
```

`.env` 가 없으면 **데모 모드**로 동작합니다(이 브라우저에만 저장, 탭 여러 개로 배틀 시험 가능).
데모 모드에서는 학번 `1101`~`1106` 이 미리 등록되어 있고, "처음 접속"을 선택해 PIN 을 만들면 됩니다.

```bash
npm test         # 타자 엔진 단위 테스트
npm run build    # 타입 검사 + 빌드
```

## Firebase 연결

1. Firebase 프로젝트에서 Authentication(익명, 이메일/비밀번호), Firestore, Realtime Database 를 사용 설정합니다.
2. `.env.example` 을 `.env` 로 복사하고 웹 앱 설정값을 채웁니다.
3. 보안 규칙을 배포합니다.

```bash
npx firebase-tools deploy --only firestore,database --project <프로젝트 ID>
```

4. 배포 주소를 Authentication > 설정 > 승인된 도메인에 추가합니다.
5. 앱의 `선생님 모드`에서 가장 먼저 가입한 계정이 관리자가 됩니다. 관리자는 다른 선생님의 이메일을 초대할 수 있습니다.

Vercel 에 배포할 때는 `.env` 의 다섯 값(`VITE_FIREBASE_*`)을 프로젝트 환경 변수로 등록합니다.

## 학생 로그인

학번 4자리(학년 1 + 반 1 + 번호 2, 예: `1315`) + 이름 + PIN 4자리.
선생님이 명단을 등록하면, 학생은 첫 접속 때 PIN 을 직접 정합니다. PIN 을 잊으면 선생님 모드에서 초기화합니다.

## 콘텐츠

앱에는 기초 낱말·문장이 내장되어 있습니다. 수업용 과목별 콘텐츠는 선생님 모드의 `콘텐츠` 탭에서
JSON 파일로 올리며, 로그인한 학생만 볼 수 있습니다.

```json
{
  "words":     [{ "id": "w-001", "text": "낱말", "meaning": "뜻풀이", "lang": "ko", "subject": "korean", "unit": "단원", "level": 1 }],
  "sentences": [{ "id": "s-001", "text": "문장입니다.", "lang": "ko", "subject": "korean", "unit": "단원", "level": 1 }],
  "passages":  [{ "id": "p-001", "title": "제목", "text": "긴 글...", "lang": "ko", "subject": "korean", "unit": "단원", "level": 2 }]
}
```

`subject` 는 `korean` `english` `math` `science` `social` 중 하나, `lang` 은 `ko` 또는 `en` 입니다.

## 구조

| 경로 | 내용 |
|---|---|
| `src/engine` | 자모 분해, 오타 판정, 타수 계산, 단계·점수·배틀 일정 (순수 로직 + 테스트) |
| `src/data` | 데이터 계층 (Firebase / 데모 모드) |
| `src/pages`, `src/components` | 화면 |
| `firestore.rules`, `database.rules.json` | 보안 규칙 |
| `docs` | 기획 문서 |

## 알아 둘 점

- 서버 없이 보안 규칙만으로 권한을 관리합니다. 4자리 PIN 은 수업용 수준의 보호입니다.
- 소리는 기본으로 꺼져 있습니다.
