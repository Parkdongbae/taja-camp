# 4. 피드백·게이미피케이션 기획서

> 목적: 매 수업 10분 연습이 지루하지 않고, 학기 내내 다시 하고 싶게 만든다.
> 대상: 중학교 1학년. 정보 수업 시간에 교실(컴퓨터실)에서 함께 사용한다.

## 1. 기획 원칙

| 원칙 | 내용 |
|---|---|
| 정확도가 먼저 | 속도보다 정확도를 보상한다. 정확도 90% 미만 기록은 최고 기록·순위·보상에서 뺀다 |
| 잃지 않는다 | 포인트·계급·단계는 내려가지 않는다. 실패해도 "얼마나 남았는지"를 보여 준다 |
| 어제의 나와 비교 | 순위는 일부 학생만 즐겁다. 모든 학생에게는 "지난주보다 +○타"를 가장 크게 보여 준다 |
| 10분 안에 한 번은 성취 | 한 번의 수업에서 최소 1회는 승급·배지·기록 갱신 중 하나를 경험하도록 목표를 잘게 나눈다 |
| 교실에서 방해되지 않게 | 소리는 기본 꺼짐. 효과는 짧고(1초 이내) 다음 입력을 막지 않는다 |

## 2. 즉각 피드백 (글쇠를 누르는 순간)

### 2.1 시각 효과

| 상황 | 효과 | 지속 |
|---|---|---|
| 정타 | 글자가 진한 색으로 바뀜, 가상 키보드 글쇠가 살짝 눌림 | 0.1초 |
| 오타 | 글자 빨강 + 빨간 밑줄, 잘못 누른 글쇠 빨갛게, 입력창 좌우 흔들림(4px) | 0.3초 |
| 연속 정타 10 / 30 / 50 / 100 | 화면 오른쪽 위에 `🔥 30 연속!` 표시, 숫자가 커질수록 색이 진해짐 | 1초 |
| 연속 정타 끊김 | 연속 숫자가 조용히 0으로 (벌점 연출 없음) | — |
| 낱말·문장 완성 | 카드가 위로 밀려 나가며 다음 것이 들어옴 | 0.2초 |
| 자리연습 정타 | 손 실루엣의 해당 손가락이 눌렀다 돌아오는 동작 | 0.15초 |
| 최고 기록 갱신 순간 | 왼쪽 패널 타수 숫자에 금색 테두리 | 계속 |

### 2.2 타건음 (기본값: 꺼짐, F2 로 전환)

| 소리 | 설명 |
|---|---|
| 정타 | 짧은 기계식 키보드 소리. 3가지 변형을 무작위로 재생해 단조로움을 줄임 |
| 오타 | 낮고 짧은 "툭" 소리. 경고음처럼 날카롭지 않게 |
| 완성 | 맑은 "딩" |
| 승급·진급 | 2초 이내의 짧은 팡파르 |
| 테마 선택 | 기계식 / 타자기 / 물방울 (경험치로 해금) |

- Web Audio API 로 미리 불러와 지연 없이 재생한다. 음량 조절 가능.
- 교사가 `수업 설정`에서 반 전체 소리를 강제로 끌 수 있다.

### 2.3 연습 직후 피드백 (결과 창)

1. 타수·정확도·오타 수와 **지난 기록 대비 변화**(▲19타).
2. 약점 글쇠 3개와 `[약점 글쇠 연습]` 버튼 → 그 글쇠가 든 낱말만 20개 출제.
3. 한 줄 코칭 문구(상황별 자동 선택).

| 상황 | 문구 예 |
|---|---|
| 정확도 90% 미만 | "속도를 조금 늦추고 정확하게 쳐 볼까요? 정확도 90%부터 기록으로 인정돼요." |
| 특정 글쇠 반복 오타 | "`ㅛ`는 오른손 검지를 위로 뻗어요. 약점 글쇠 연습을 해 보세요." |
| 기록 갱신 | "최고 기록! 지난주보다 19타 빨라졌어요." |
| 정확도 100% | "오타 0개! 완벽해요." |

## 3. 성장 구조

성장 축은 세 가지이며 서로 다른 것을 보상한다.

| 축 | 무엇을 보상하나 | 화면 표시 |
|---|---|---|
| ① 자리연습 단계 (10단계) | 정확한 자리 익히기 | 단계 지도, 상단 `자리 4/10` |
| ② 계급 (훈련병~예비역) | 배틀 실력 | 상단 계급장, 순위표 |
| ③ 경험치·레벨 | **꾸준함과 연습량** (실력과 무관하게 누구나 오름) | 홈 화면 경험치 막대 |

### 3.1 자리연습 단계 — "훈련소" 서사

- 프로그램 전체를 **타자 훈련소**로 설정한다. 자리연습은 "기초 군사 훈련", 수료하면 배틀(실전)에 나갈 수 있다는 이야기로 계급 체계와 자연스럽게 이어진다.
- 단계 통과마다 `승급되었습니다!` 창 + 단계 지도에 도장이 찍힌다.
- 10단계 모두 통과 시 `수료증`(이름·날짜·평균 점수가 적힌 화면, 인쇄 가능)을 준다.

### 3.2 계급

| 계급 | 필요 RP | 계급장 | 방 분위기 색 |
|---|---|---|---|
| 훈련병 | 0 | 무늬 없음 | 회색 |
| 이등병 | 100 | 작대기 1 | 초록 |
| 일병 | 300 | 작대기 2 | 파랑 |
| 상병 | 600 | 작대기 3 | 보라 |
| 병장 | 1,000 | 작대기 4 | 주황 |
| 예비역 | 1,500 | 별 | 금색 |

- 진급하면 `진급을 축하합니다!` 창과 함께 이름 옆 계급장이 바뀐다.
- 다음 계급까지 남은 RP 를 항상 막대로 보여 준다.

### 3.3 경험치(XP)와 레벨

```
연습 1회 XP = 기본 10 + 정확도 보너스(95% 이상 +5, 100% +10) + 기록 갱신 +10
배틀 1회 XP = 15 (순위 무관)
퀴즈 1회 XP = 기본 10 + 정답 1개당 +1 (최대 20)
하루 목표(10분) 달성 = +30
```

- 레벨은 XP 100마다 1 오른다. 레벨은 순위 경쟁에 쓰지 않고 **꾸미기 해금**에만 쓴다.
- 해금 항목: 캐릭터(첨부 이미지의 유령 같은 프로필 캐릭터) 8종, 타건음 테마 3종, 가상 키보드 색 테마 5종.

## 4. 목표와 리텐션 장치

### 4.1 오늘의 훈련 (일일 목표)

- 목표: **하루 10분**(교사가 5~20분으로 조정). 홈 화면 맨 위에 진행 막대로 표시한다.
- 실제 입력 시간만 센다(일시정지·대기 시간 제외).
- 달성하면 `오늘의 훈련 완료!` 도장 + XP 30. 10분 이후에도 계속 연습할 수 있다.
- **권장 10분 루틴**을 홈의 `이어서 하기`가 자동으로 안내한다.

| 순서 | 시간 | 내용 |
|---|---|---|
| 1 | 2분 | 몸 풀기: 지난 시간 약점 글쇠 |
| 2 | 5분 | 본 훈련: 자리연습 진행 중이면 자리연습, 수료했으면 낱말·단문 |
| 3 | 3분 | 도전: 승급 테스트 또는 장문·배틀 |

### 4.2 연속 출석

- 연습한 **수업일** 기준으로 센다. 주말·수업 없는 날은 끊기지 않는다(주 1~2회 수업이므로 "지난 수업에 이어 연속 ○회"로 계산).
- 3·5·10·20회 연속에 배지를 준다.
- 내 기록 화면에 연습 달력(잔디)을 보여 준다.

### 4.3 성장 그래프

| 그래프 | 내용 |
|---|---|
| 타수 성장 | 주별 평균·최고 타수 꺾은선(한글/영문). 첫 주 기록을 점선으로 남겨 성장 폭을 보여 줌 |
| 정확도 | 주별 평균 정확도 |
| 약점 글쇠 지도 | 키보드 그림 위에 오타율을 색 농도로 표시. 누르면 그 글쇠 연습으로 이동 |
| 단계 진행 | 자리연습 10단계 통과 날짜 |

### 4.4 배지

| 분류 | 배지 | 조건 |
|---|---|---|
| 자리 | 기본기 탄탄 | 기본자리 테스트 100점 |
| 자리 | 훈련소 수료 | 한글 8단계 + 기호 2단계 통과 |
| 자리 | 안 보고 치기 | 키보드·손 표시를 끄고 테스트 통과 |
| 정확 | 무결점 | 단문연습 정확도 100% |
| 정확 | 명사수 | 정확도 95% 이상 10회 연속 |
| 속도 | 100타 / 200타 / 300타 / 400타 돌파 | 정확도 90% 이상 기록 기준 |
| 꾸준 | 개근 3 / 5 / 10 / 20 | 연속 출석 |
| 어휘 | 과목 정복 (국·영·수·과·사) | 해당 과목 낱말을 모두 1회 이상 정확히 입력 |
| 배틀 | 첫 승리 / 10승 / 역전의 용사 | 배틀 1등 / 누적 / 마지막 20초에 순위 3계단 상승 |
| 영문 | 바이링구얼 | 영문 자리 7단계 통과 |

배지는 순위와 달리 **모든 학생이 받을 수 있는 조건**을 절반 이상으로 구성한다.

## 5. 경쟁과 협동

### 5.1 배틀 (개인 경쟁)

- 규칙은 1번 문서 6장. 같은 계급끼리만 겨루므로 실력 차로 인한 좌절이 작다.
- 경기 중 연출: 낱말을 가져가면 내 색으로 터지는 효과, 연속 3개 획득 시 `연속 획득!`, 마지막 20초는 배경색이 바뀌고 속도가 빨라진다.
- 꼴찌도 RP 5 를 받는다(1점 이상 획득 시).

### 5.2 반 대항 (협동)

- **이번 주 우리 반 기록**: 반 전체의 일일 목표 달성률과 평균 타수 증가량을 반별로 비교한다.
- 잘하는 학생 한 명이 아니라 **참여율**이 순위를 결정하므로, 서로 독려하게 된다.
- 순위표의 `성실 순위`·`이번 주 성장 순위`도 같은 취지다(타수가 낮아도 1등 가능).

### 5.3 순위 공개 범위

- 순위표는 상위 20명 + 내 순위만 보여 준다. 하위권이 드러나지 않는다.
- 교사가 순위표 전체를 끌 수 있다.

## 6. 어휘력 신장 장치 (교육 효과)

| 장치 | 내용 |
|---|---|
| 뜻풀이 함께 보기 | 낱말연습에서 교과 용어 아래에 한 줄 뜻풀이를 보여 준다 |
| 과목 선택 | 시험 기간에 해당 과목 낱말만 골라 연습할 수 있다 |
| 오늘의 낱말 | 홈 화면에 하루 한 개 교과 용어와 뜻을 보여 준다 |
| 낱말 수집장 | 정확히 입력한 낱말이 과목별 수집장에 채워진다(○○/120). 과목 정복 배지와 연결 |
| 영어 낱말 | 영문으로 입력하고 우리말 뜻을 함께 본다 |
| 뜻 맞추기 퀴즈 | 뜻풀이를 보고 보기 4개 중 맞는 낱말을 직접 쳐서 답한다. 한 판 10문제, 문제당 15초. 점수는 전체 순위의 퀴즈 탭에 쌓이며 배틀 계급(RP)과는 별개다(1번 문서 7장) |
| 배틀 낱말 | 배틀에 나오는 낱말도 교과 용어이므로 놀면서 반복 노출된다 |

## 7. 하지 않는 것

| 하지 않는 것 | 이유 |
|---|---|
| 포인트 차감·강등 | 중1 초보자의 의욕을 꺾는다 |
| 유료 요소·뽑기 | 수업용 |
| 채팅 | 수업 방해·언어폭력 위험. 배틀에는 정해진 응원 이모지 4종만 둔다 |
| 긴 연출·컷신 | 10분 수업에서 시간 낭비 |
| 전체 꼴찌 공개 | 낙인 방지 |
