# 5. MVP 범위 및 기술 검증(PoC)

> 목적: 무엇을 먼저 만들지 정하고, 만들기 전에 확인해야 할 기술 위험을 점검한다.

## 1. 확정된 결정

| 항목 | 결정 | 근거 |
|---|---|---|
| 저장 방식 | **회원제 (Firebase)**. 로컬 저장은 설정값(소리·표시)만 | 컴퓨터실은 자리가 바뀌고 PC 가 초기화되므로 로컬 저장으로는 기록이 유지되지 않는다. 배틀·순위도 서버가 필요하다 |
| 구글 시트 vs Firebase | **Firebase** | 16명 실시간 배틀은 초 단위 동기화와 동시 쓰기 충돌 처리가 필요하다. 구글 시트는 응답이 수 초 걸리고 호출 한도가 있어 불가능하다. 성적은 CSV 내보내기로 시트에서 열 수 있다 |
| 학생 로그인 | 학번(4자리) + 이름 + PIN 4자리 | 도용 방지. 익명 로그인 후 보안 규칙이 학번·이름·PIN 해시를 대조 |
| 교사 인증 | Firebase 이메일/비밀번호 로그인. 처음 가입한 교사가 관리자, 관리자가 다른 교사의 이메일을 초대 | 학생 추가·삭제 권한을 보안 규칙에서 강제 |
| 서버 구조 | 서버 함수(Vercel Functions)·Firebase Admin·맞춤 토큰 없음. 권한은 보안 규칙만으로 강제 | 서비스 계정 키를 관리하지 않아도 된다 |
| 키보드 | 데스크톱 키보드·노트북 키보드·서피스 고3(타입 커버) 3종 지원. 학생이 키보드 종류를 고름 | 가상 키보드 맨 아랫줄만 다르고 판정은 같다 |
| 배틀 개방 | 한글 자리 8단계 + 기호 2단계 통과 | |
| Firebase 프로젝트 | 새로 만든다 | |
| 배포 | GitHub(공개 저장소) → Vercel | 교과서 원본·추출 콘텐츠는 올리지 않음 |

## 2. 기술 구성

| 영역 | 선택 | 비고 |
|---|---|---|
| 프런트엔드 | React + TypeScript + Vite | 단일 페이지 앱. Vercel 정적 배포 |
| 스타일 | Tailwind CSS | |
| 상태 관리 | Zustand | 타자 엔진 상태는 React 바깥의 순수 모듈로 분리(테스트 용이) |
| 인증 | Firebase Auth (학생: 익명 로그인 + `links/{uid}` 증명, 교사: 이메일/비밀번호) | |
| 데이터 | Firestore + Realtime Database | 3번 문서 |
| 서버 | 서버 함수·Firebase Admin 없음 | 로그인·승급·RP 정산은 클라이언트가 계산하고 보안 규칙이 범위를 검증 |
| 그림 | 로그인 마스코트·승급/진급 축하 창 그림은 캔바(Canva)로 제작해 `public/` 에 둔다. 가상 키보드·손 실루엣은 글쇠마다 손가락이 움직여야 하므로 코드(SVG)로 그린다 | |
| 데모 모드 | Firebase 설정이 없으면 브라우저 저장(`localBackend`)으로 동작 | 탭 간 배틀 시험 가능. 개발·시연용 |
| 테스트 | Vitest(타자 엔진 단위 테스트), Playwright(브라우저 입력 테스트) | |
| 콘텐츠 추출 | Python + PyMuPDF (로컬 스크립트) | 교과서 PDF → 낱말·문장 후보 (`content-data/` JSON, 깃허브 제외) |

무료 요금제 적합성(추정): 학생 300명이 주 2회 10분 사용 시 Firestore 읽기·쓰기는 무료 한도(일 읽기 5만·쓰기 2만) 안이다. 콘텐츠(약 1,000건)는 로그인 때 한 번 받아 브라우저에 보관해 읽기 수를 줄인다. Realtime Database 동시 접속 100명 제한(무료)은 동시 접속이 최대 30명(한 반)이므로 문제없다.

### 4.1 PoC 1 결과: 교과서 PDF 추출 (완료)

| 과목 | 추출 | 품질 | 유의점 |
|---|---|---|---|
| 수학 | 가능 | 중상 | 수식 기호가 깨짐(거듭제곱, ≥ 등) → **문장보다 용어 위주** |
| 과학 | 가능 | 상 | |
| 영어 | 가능 | 상 | 단어 목록(단어/품사/뜻)이 있어 낱말 자료로 최적 |
| 국어 | 가능 | 중 | 제목 장식 글자·시 행 번호가 섞임 |
| 사회 | 가능 | 중상 | 초성 힌트·줄 번호가 섞임 |

- 모두 글자 정보가 들어 있는 PDF 라서 OCR 이 필요 없다. 한글 깨짐 없음.
- 가장 큰 파일(667MB)도 전체 추출 8초, 메모리 약 230MB 로 문제없다.
- **공통 문제**: 줄 끝에서 낱말이 잘려 이어 붙이면 `식 량`, `카메 라`처럼 낱말 중간에 공백이 생긴다. → 의심 문장은 자동으로 걸러 내고 사람이 검수한다. 단문·장문은 이 검수를 거친 **교과서 원문 발췌**로 구성한다.
- HWP 파일은 열어 보지 않았다(PDF 로 충분).

사용 범위: 5과목 전 단원 사용(모두 1학기 범위).

### 4.2 PoC 2·3 계획: 브라우저 글쇠 이벤트

시험 대상: Windows 의 Chrome, Edge, Whale (학교 PC 에 설치된 브라우저 기준). Microsoft 한글 입력기. 데스크톱 키보드·노트북 키보드·서피스 고3(타입 커버) 모두에서 시험한다.

| 확인할 것 | 예상 | 대비책 |
|---|---|---|
| 한글 조합 중 `keydown` 의 `event.key` | `Process`, `keyCode 229` 로 들어옴 | 자리연습은 `event.code` 만 사용 |
| `event.code` 가 한/영 상태와 무관하게 물리 글쇠를 주는가 | 준다 | 주지 않는 브라우저는 지원 대상에서 제외 |
| `compositionupdate` / `input` 이벤트 순서와 값 | 브라우저마다 순서가 다름 | 이벤트 종류에 의존하지 않고 **입력창의 현재 값만** 읽어 자모열 비교 |
| 조합 중 Enter·Space | 조합 확정과 제출이 겹쳐 두 번 처리될 수 있음 | `isComposing` 확인 후 `compositionend` 다음 프레임에 제출 처리 |
| 조합 중 백스페이스 | 자모 단위로 지워짐 | 값 기준 비교라 영향 없음 |
| 한/영 키, CapsLock 상태 감지 | 직접 감지 불가 | 입력값에 영문이 들어오면 안내 문구 표시 |
| 붙여넣기·자동완성·맞춤법 검사 | 방해 요소 | `paste` 차단, `autocomplete/spellcheck off` |
| 키를 누르고 있을 때 반복 입력 | `event.repeat` | 무시 |

산출물: 이벤트 기록 표(브라우저 × 상황), 타자 엔진 입력 어댑터 설계 확정.

### 4.3 PoC 4 계획: 16명 실시간 배틀

1. 방 하나에 가상 참가자 16명(스크립트)이 같은 낱말을 동시에 제출 → 트랜잭션으로 정확히 1명만 선점되는지 1,000회 반복.
2. 선점 결과가 다른 참가자 화면에 반영되는 지연 측정(목표 200ms 이내).
3. `serverTimeOffset` 보정 후 낱말 등장 시각 오차 측정(목표 100ms 이내).
4. 참가자 강제 종료 시 `onDisconnect` 로 목록에서 빠지는지.
5. 경기 1회당 쓰기 횟수·전송량 → 무료 한도 대비 하루 가능 경기 수 계산.

실패 시 대안: 방 정원을 8명으로 줄인다(서버 함수는 쓰지 않는다).

| 학교 방화벽이 Firebase 를 차단 | 서비스 전체 불가 | **확인 완료** — 학교에서 Firebase·Vercel 접속 됨 |

| 교과서 문장 저작권 | 공개 배포 시 문제 소지 | 교육 목적 원문 발췌. 원본·추출 콘텐츠는 깃허브에 올리지 않고, 교사가 JSON 으로 올려 Firestore 에 저장하며 로그인 사용자만 열람. 앱에는 직접 쓴 기초 콘텐츠만 내장. 저장소가 공개이므로 공개 파일에 교과서 내용을 적지 않음 (3번 문서 8장) |
| 학생이 개발자 도구로 기록 조작 | 순위 왜곡 | 승급·RP 는 클라이언트가 계산하되 보안 규칙이 범위 검증(RP 1회 +80 이하, 자리 단계 1회 +1 이하 등). 규칙 범위 안의 부풀리기는 막지 못함 (1번 문서 10장) |
| 4자리 PIN 무차별 대입 | 친구 계정 도용 | 5회 실패 잠금은 규칙만으로 불가 → 수업용 수준의 보호로 받아들임 (1번 문서 10장) |
| PIN 분실 다발 | 수업 지연 | 교사 화면에서 한 번에 초기화(`secrets` 삭제) |
| 한글 조합 판정 오류 | 정타가 오타로 표시 → 신뢰 상실 | 단위 테스트 200건 + 실제 브라우저 시험 |
| 서비스 계정 키 유출 | 해당 없음 | 서비스 계정 키를 쓰지 않는다(서버 함수·Admin SDK 없음). 권한은 보안 규칙만으로 강제 |
