# 우리 학교에 타자 훈련소 설치하기

구글 계정 하나만 있으면 됩니다. 프로그램을 내려받거나 설치할 필요가 없고, 요금도 들지 않습니다(Firebase 무료 요금제).
걸리는 시간은 5~10분, 직접 입력하는 명령은 **한 줄**입니다.

## 준비

- 구글 계정 (학교 계정에서 프로젝트 만들기가 막혀 있으면 개인 계정을 쓰세요)
- Firebase 를 한 번도 써 본 적이 없다면 <https://console.firebase.google.com> 을 먼저 한 번 열어 약관에 동의해 주세요.

## 1단계. 설치 화면 열기

저장소 첫 화면(README)의 **Open in Cloud Shell** 버튼을 누릅니다.
"저장소를 신뢰하시겠습니까?" 라고 물으면 **신뢰**를 고르고 확인합니다.
(구글이 제공하는 무료 웹 터미널이 열리고, 이 저장소가 자동으로 내려받아집니다.)

## 2단계. 설치 명령 한 줄 실행

아래 명령을 터미널에 붙여 넣고 Enter 를 누릅니다.

```bash
npm run setup
```

- "Cloud Shell 승인" 창이 뜨면 **승인**을 누릅니다.
- 로그인 주소가 나오면 그 주소를 열어 구글 계정으로 허용하고, 받은 코드를 터미널에 붙여 넣습니다(나오지 않으면 건너뜁니다).
- 나머지는 자동입니다: 프로젝트 만들기 → 데이터베이스 만들기 → 로그인 방식 켜기 → 보안 규칙 올리기 → 사이트 올리기.

끝나면 이렇게 나옵니다.

```
🎉 설치가 끝났습니다!
사이트 주소: https://taja-xxxxxxxx.web.app
```

## 3단계. 선생님 계정 만들기

1. 사이트 주소를 열고 아래쪽 **선생님 모드** → **처음이면 교사 계정 만들기**.
   가장 먼저 가입한 계정이 관리자가 됩니다. 다른 선생님은 관리자가 이메일로 초대합니다.
2. **학생 관리**에서 학번(4자리: 학년 1 + 반 1 + 번호 2)과 이름을 등록합니다. 엑셀에서 복사해 한꺼번에 붙여 넣을 수 있습니다.
3. 학생에게 사이트 주소를 알려 줍니다. 학생은 첫 접속 때 PIN 4자리를 직접 정합니다.

## 자주 묻는 것

**새 버전이 나오면?** 같은 버튼으로 Cloud Shell 을 열고 아래를 실행합니다. 학생 기록은 그대로 남습니다.

```bash
git pull && npm run setup
```

Cloud Shell 을 오래 쓰지 않아 폴더가 사라졌다면, 처음 설치 때 나온 프로젝트 ID(주소의 `taja-xxxxxxxx`)를 붙여 실행합니다.

```bash
npm run setup -- --project taja-xxxxxxxx
```

**중간에 멈췄어요.** `npm run setup` 을 다시 실행하면 이어서 진행합니다. 화면에 원인과 할 일이 한국어로 나옵니다.

- "프로젝트를 만들지 못했습니다" → 위 "준비"의 약관 동의를 했는지, 학교 계정 제한이 아닌지 확인하세요.
- "Realtime Database 는 직접 한 번 만들어 주세요" → 화면에 나온 주소를 열어 [데이터베이스 만들기]를 누른 뒤 Enter.
- "로그인 방식을 직접 켜 주세요" → 화면에 나온 주소에서 "익명"과 "이메일/비밀번호"를 사용 설정한 뒤 다시 실행.

**정말 무료인가요?** 결제 수단을 등록하지 않는 무료(Spark) 요금제만 씁니다. 한 반(30명)이 동시에 쓰는 규모는 무료 한도 안입니다.

**주소를 학교 이름으로 바꾸고 싶어요.** Firebase 콘솔 → Hosting → [사이트 추가] 또는 [커스텀 도메인 추가]에서 할 수 있습니다.

**교과 낱말을 넣고 싶어요.** 선생님 모드의 **콘텐츠** 탭에서 JSON 파일로 올립니다(형식은 README 참고). 올린 뒤 **수업 설정 → 연습·배틀 콘텐츠**에서 낼 과목·단원을 고를 수 있습니다.

**내 컴퓨터에서 설치하려면?** Node.js 20 이상을 설치하고 저장소를 내려받은 폴더에서 `npm install` 뒤 `npm run setup` 을 실행합니다. 이 경우 Realtime Database 만들기 한 단계는 화면 안내에 따라 직접 눌러야 합니다.
