# 1. 핵심 로직·계산 규칙 명세서

> 목적: 타수·정확도·오타 판정·승급·배틀 점수·퀴즈 점수의 기준을 하나로 통일한다.
> 모든 화면(자리/낱말/단문/장문/배틀/퀴즈)과 보안 규칙 검증은 이 문서의 규칙만 따른다.

확정된 전제

| 항목 | 결정 |
|---|---|
| 자판 | 한글 두벌식 표준, 영문 QWERTY |
| 저장소 | Firebase (Firestore + Realtime Database) |
| 학번 | 4자리 (학년 1자리 + 반 1자리 + 번호 2자리, 예: `1315` = 1학년 3반 15번) |
| 학생 로그인 | 학번 + 이름 + PIN 4자리 (Firebase 익명 로그인 + 보안 규칙 검증) |
| 교사 인증 | Firebase 이메일/비밀번호 로그인 |
| 키보드 | 데스크톱 키보드·노트북 키보드·서피스 고3(타입 커버) 3종 지원. 학생이 종류를 고르며 가상 키보드 그림의 맨 아랫줄만 달라지고 판정은 같다 |
| 배틀 개방 | 한글 자리 8단계 + 기호 2단계 통과 |

## 1. 용어

| 용어 | 정의 |
|---|---|
| 타(keystroke) | 글쇠를 한 번 누른 것. Shift 조합은 2타로 센다. |
| 자모열 | 글을 두벌식 글쇠 순서로 풀어 쓴 열. 예) `값` → `ㄱ ㅏ ㅂ ㅅ` |
| 정타 | 목표 자모열과 일치하게 입력된 타 |
| 오타 | 목표와 다르게 입력된 타 (고쳐도 기록에 남는다) |
| 타수 | 1분당 정타 수 (타/분) |
| 정확도 | 정타 ÷ (정타 + 오타) × 100 |

## 2. 한글 자소 분리와 타수 기준

### 2.1 음절 분해

완성형 한글(U+AC00~U+D7A3)은 다음 식으로 초성·중성·종성으로 나눈다.

```
code   = 음절코드 - 0xAC00
초성   = floor(code / 588)        (19종)
중성   = floor((code % 588) / 28) (21종)
종성   = code % 28                (0 = 받침 없음, 27종)
```

### 2.2 글쇠 단위 전개 (타수표)

| 구분 | 글자 | 글쇠 전개 | 타수 |
|---|---|---|---|
| 홑자음 | ㄱ ㄴ ㄷ ㄹ ㅁ ㅂ ㅅ ㅇ ㅈ ㅊ ㅋ ㅌ ㅍ ㅎ | 그대로 | 1 |
| 쌍자음 | ㄲ ㄸ ㅃ ㅆ ㅉ | Shift + 홑자음 | 2 |
| 홑모음 | ㅏ ㅑ ㅓ ㅕ ㅗ ㅛ ㅜ ㅠ ㅡ ㅣ ㅐ ㅔ | 그대로 | 1 |
| Shift 모음 | ㅒ ㅖ | Shift + ㅐ/ㅔ | 2 |
| 겹모음 | ㅘ(ㅗㅏ) ㅙ(ㅗㅐ) ㅚ(ㅗㅣ) ㅝ(ㅜㅓ) ㅞ(ㅜㅔ) ㅟ(ㅜㅣ) ㅢ(ㅡㅣ) | 두 글쇠 | 2 |
| 겹받침 | ㄳ ㄵ ㄶ ㄺ ㄻ ㄼ ㄽ ㄾ ㄿ ㅀ ㅄ | 두 글쇠 | 2 |
| 받침 쌍자음 | ㄲ ㅆ | Shift + 홑자음 | 2 |
| 띄어쓰기 | (공백) | Space | 1 |
| 줄바꿈 | ↵ | Enter | 1 |
| 숫자·기본 문장부호 | `1` `,` `.` 등 | 그대로 | 1 |
| Shift 기호 | `! @ # $ % ^ & * ( ) ? " :` 등 | Shift + 글쇠 | 2 |
| 영문 소문자 | a~z | 그대로 | 1 |
| 영문 대문자 | A~Z | Shift + 글쇠 | 2 |

예시

| 글 | 자모열 | 타수 |
|---|---|---|
| 나라 | ㄴㅏㄹㅏ | 4 |
| 값 | ㄱㅏㅂㅅ | 4 |
| 꽃 | (Shift)ㄱ ㅗ ㅊ | 4 |
| 과학 | ㄱㅗㅏㅎㅏㄱ | 6 |
| Hello! | (S)h e l l o (S)1 | 8 |

### 2.3 타수 공식

```
타수(타/분) = 정타 수 ÷ 경과 시간(분)
경과 시간   = 첫 글쇠를 누른 순간 ~ 마지막 정타 순간 (일시정지 구간 제외)
```

- 백스페이스·방향키·한/영 키는 타수에 넣지 않는다.
- 경과 시간이 3초 미만이면 타수를 표시하지 않는다(값이 튀는 것 방지).
- 화면의 실시간 타수는 0.5초마다 갱신하고, 최근 5초 이동 평균을 쓴다. 저장하는 값은 전체 구간 평균이다.
- 영문은 `WPM = 타수 ÷ 5` 를 함께 표시한다.
- 타수 1,500타/분 초과 기록은 비정상으로 보고 저장하지 않는다(붙여넣기·매크로 방지).

### 2.4 정확도 공식

```
정확도(%) = 정타 ÷ (정타 + 오타) × 100   (소수 둘째 자리에서 반올림)
```

오타는 백스페이스로 고쳐도 누적 오타에 남는다. "고치면 사라지는 오타"는 정확한 타자 습관을 길러 주지 못하기 때문이다.

## 3. 입력 판정 방식 (연습 종류별)

연습 종류에 따라 판정 방식이 다르다. 이것이 이 프로그램의 가장 중요한 기술 결정이다.

| 연습 | 판정 방식 | 이유 |
|---|---|---|
| 자리연습·승급 테스트·기호연습 | **물리 글쇠 판정** (`KeyboardEvent.code`) | 한/영 상태와 무관하게 "어느 자리를 눌렀는가"만 본다. 조합(IME) 문제가 없다. |
| 낱말·단문·장문·배틀 | **자모열 접두 비교** (입력창 값 기준) | 실제 글 입력 능력을 본다. 한글 조합 중 상태를 정확히 판정해야 한다. |

### 3.1 물리 글쇠 판정 (자리연습)

- `keydown` 이벤트의 `event.code`(예: `KeyS`)와 `event.shiftKey` 로 판정한다. `event.key` 는 한/영 상태에 따라 달라지므로 쓰지 않는다.
- 목표 글쇠와 같으면 정타, 다르면 오타 1회. **맞는 글쇠를 누를 때까지 다음 글자로 넘어가지 않는다.**
- 같은 문항에서 오타는 최대 3회까지만 센다(연타로 정확도가 0이 되는 것 방지).
- `event.repeat === true`(키를 누르고 있는 자동 반복)는 무시한다.
- 쌍자음·Shift 기호 문항은 Shift 를 누른 상태여야 정타다. Shift 없이 누르면 오타로 처리하고 "Shift 를 함께 누르세요" 안내를 띄운다.
- 화면에는 목표 글쇠 강조 + 눌러야 할 손가락 실루엣을 표시한다(→ 2번 문서).

### 3.2 자모열 접두 비교 (낱말·단문·장문·배틀)

숨김 없는 실제 `<input>`/`<textarea>` 에 입력받고, 값이 바뀔 때마다(`input`, `compositionupdate`) 아래를 수행한다.

```
T = 목표 글의 자모열
I = 현재 입력값의 자모열
판정: I 가 T 의 접두(prefix)이면 "정상 진행", 아니면 처음 어긋난 위치부터 "오타"
```

음절 단위가 아니라 자모열로 비교하는 이유(조합 중 오타 오판 방지):

| 목표 | 입력 과정 | 음절 비교 | 자모열 비교 |
|---|---|---|---|
| 가나 | `ㄱ`→`가`→`간`→`가나` | `간` ≠ `가` 로 오타 오판 | ㄱㅏㄴ 은 ㄱㅏㄴㅏ 의 접두 → 정상 |
| 달기 | `달`→`닭`→`달기` | `닭` ≠ `달` 오판 | ㄷㅏㄹㄱ 접두 → 정상 |
| 한글 | `ㅎ`→`하`→`한` | `하` ≠ `한` 오판 | ㅎㅏ 접두 → 정상 |

화면 표시 규칙

| 상태 | 표시 |
|---|---|
| 확정된 정타 음절 | 진한 글자색 |
| 조합 중이며 접두 일치 | 밑줄 + 중립색 (오타 아님) |
| 어긋난 음절 | 빨간 글자 + 빨간 밑줄, 해당 글쇠를 가상 키보드에 빨갛게 0.3초 표시 |
| 아직 입력 안 한 부분 | 연한 회색 |

오타 집계 규칙

1. 자모열이 접두에서 벗어나는 **순간** 오타 1회를 기록한다. 기록 단위는 어긋난 자모(글쇠) 1개.
2. 같은 위치에서 고치지 않고 계속 치면 추가 오타는 세지 않는다(한 번 틀린 뒤 이어 친 글자가 전부 오타가 되는 것 방지). 고쳤다가 같은 자리에서 다시 틀리면 다시 1회.
3. 오타가 난 자모는 `어떤 글쇠를 쳐야 했는데(목표) 무엇을 쳤는지(입력)` 쌍으로 저장해 약점 글쇠 분석에 쓴다.
4. 정타 수는 "지금까지 접두가 일치한 최대 길이"로 센다. 지웠다가 다시 친 글쇠는 중복 계산하지 않는다.

진행 규칙

| 연습 | 넘어가는 조건 |
|---|---|
| 낱말 | 낱말을 정확히 치고 Space 또는 Enter. 틀린 채로 제출하면 오타 1회 추가 후 다음 낱말로(막힘 방지). |
| 단문 | 문장을 **오타 없이** 완성하고 Enter. 오타가 남아 있으면 넘어가지 않고 입력창이 흔들린다. |
| 장문 | 한 줄을 다 치면 자동으로 다음 줄. 오타가 있어도 줄 길이만큼 치면 넘어가며 오타로 집계된다. |

공통 금지·예외

- 붙여넣기(`paste`), 드래그 앤 드롭 입력을 막는다.
- 창이 포커스를 잃으면 자동 일시정지한다(시간 정지).
- 10초 이상 입력이 없으면 일시정지한다.
- 한글 연습에서 영문 상태로 치고 있으면(입력값이 영문 자모로 들어오면) "한/영 키를 눌러 한글로 바꾸세요" 안내를 띄우고 오타로 세지 않는다. 영문 연습도 반대로 같다.
- 유니코드 정규화는 NFC 로 통일한다. 곱슬 따옴표(“ ”)·말줄임표(…) 등은 콘텐츠 제작 단계에서 자판으로 칠 수 있는 글자(`"`, `...`)로 바꿔 둔다.

## 4. 자리연습 단계와 승급 규칙

### 4.1 단계 구성

| 트랙 | 단계 | 이름 | 새로 배우는 글쇠 |
|---|---|---|---|
| 한글 | K1 | 기본자리 | ㅁ ㄴ ㅇ ㄹ / ㅓ ㅏ ㅣ ; |
| 한글 | K2 | 왼손윗자리 | ㅂ ㅈ ㄷ ㄱ |
| 한글 | K3 | 왼손아랫자리 | ㅋ ㅌ ㅊ ㅍ |
| 한글 | K4 | 가운데자리 | ㅅ ㅛ / ㅎ ㅗ / ㅠ |
| 한글 | K5 | 오른손윗자리 | ㅕ ㅑ ㅐ ㅔ |
| 한글 | K6 | 오른손아랫자리 | ㅜ ㅡ , . / |
| 한글 | K7 | 전체자리 | 전체 + Shift (ㅃ ㅉ ㄸ ㄲ ㅆ ㅒ ㅖ) |
| 한글 | K8 | 숫자자리 | 1 2 3 4 5 6 7 8 9 0 |
| 기호 | S1 | 기호 1 | ! @ # $ % ^ & * ( ) |
| 기호 | S2 | 기호 2 | - = _ + [ ] { } ; : ' " , . < > / ? ~ |
| 영문 | E1~E7 | 기본/왼손윗/왼손아랫/가운데/오른손윗/오른손아랫/전체(대문자) | 한글과 같은 자리 구분 |

- 진행 순서: K1 → … → K8 → S1 → S2. 영문 트랙(E1~E7)은 K1 통과 후 언제든 병행할 수 있다.
- **배틀 개방 조건: K1~K8 + S1~S2 모두 통과.** 영문 배틀은 추가로 E1~E7 통과 시 열린다.

### 4.2 단계별 학습 흐름

```
① 글쇠 익히기 (새 글쇠만, 30문항)
② 섞어 치기   (새 글쇠 70% + 이전 단계 글쇠 30%, 40문항)
③ 승급 테스트 (50문항) → 90점 이상이면 승급
```

①②는 몇 번이든 반복할 수 있고, ②를 1회 이상 마쳐야 ③이 열린다.

### 4.3 승급 테스트 채점

| 항목 | 규칙 |
|---|---|
| 문항 수 | 50문항 (해당 단계 글쇠 70%, 이전 단계 글쇠 30%. K1 은 100%) |
| 문항 제한 시간 | 문항당 3초. 넘기면 오답 처리 후 다음 문항 |
| 정답 | **첫 글쇠가 맞아야** 정답. 틀리면 그 문항은 오답이고 바로 다음 문항으로 간다 |
| 점수 | `정답 문항 수 ÷ 50 × 100` (2점 단위) |
| 통과 | **90점 이상** (오답 5개 이하) |
| 손가락 실루엣 | 테스트 중에는 숨긴다(강조 글쇠도 표시 안 함). 가상 키보드 배열만 보여 준다 |
| 재도전 | 제한 없음. 단, 불합격 직후에는 틀린 글쇠 위주 복습 20문항을 거쳐야 다시 응시 가능 |

통과하면 `승급되었습니다!` 창을 띄우고 다음 단계를 연다. 이미 통과한 단계의 테스트는 다시 볼 수 있으며 최고 점수만 남긴다.

테스트 통과 판정은 클라이언트가 계산해 본인 문서에 쓰고, 보안 규칙이 범위(자리 단계는 감소 불가·1회 +1 이하)를 검증한다.

## 5. 낱말·단문·장문 기록 규칙

| 항목 | 낱말 | 단문 | 장문 |
|---|---|---|---|
| 1회 분량 | 30낱말 | 10문장 | 글 1편(300~600자) 또는 제한 시간 5분 |
| 저장 값 | 타수, 정확도, 오타 수, 소요 시간, 약점 글쇠 | 같음 | 같음 + 진행률 |
| 기록 인정 | 분량의 100% 완료 | 100% 완료 | 80% 이상 진행 |
| 최고 기록 갱신 조건 | 정확도 90% 이상인 기록만 | 같음 | 같음 |

- 정확도 90% 미만 기록은 저장은 하되 최고 기록·순위에는 반영하지 않는다(속도만 올리는 난타 방지).
- 과목(국어·영어·수학·과학·사회)별로 선택해 연습할 수 있고, "섞어서"가 기본값이다.

## 6. 배틀 모드 규칙

### 6.1 입장

| 항목 | 규칙 |
|---|---|
| 입장 자격 | 한글 자리 + 기호 통과 학생 |
| 방 정원 | 최소 2명, 최대 16명 |
| 매칭 | **같은 계급끼리만** 같은 방에 들어간다 |
| 시작 | 방장이 시작 누름 또는 정원 16명이 차면 5초 후 자동 시작 |
| 경기 시간 | 기본 120초. 대기실에서 방장이 60·90·120·180·300초 중에 고른다 |
| 교사 통제 | 선생님 모드에서 배틀 허용 ON/OFF (수업 중 연습 시간 확보용) |

- 한 반(최대 30명)이 동시에 접속하면 같은 계급 안에서도 정원 16명이 차는 대로 방이 여러 개 생긴다.

### 6.2 진행

- 낱말이 위·아래·왼쪽·오른쪽 네 방향에서 나와 화면을 가로지른다(처음 3개는 위에서 아래로). 모든 참가자가 **같은 낱말을 같은 시각에** 본다.
- 입력창에 낱말을 치고 Space/Enter 로 제출한다. 화면에 있는 낱말과 정확히 일치하고 **가장 먼저** 제출한 사람이 점수를 얻는다. 그 낱말은 모두의 화면에서 사라진다.
- 반대쪽 끝에 닿은 낱말은 아무도 점수를 얻지 못하고 사라진다.
- 화면에 없는 낱말·틀린 낱말을 제출하면 0.5초 동안 입력이 잠긴다(마구 치기 방지).
- 낙하 속도: 시작 10초에 걸쳐 떨어지던 것이 경기 끝에는 6초로 빨라진다. 동시에 떠 있는 낱말 수는 `3 + 참가 인원` 개(4~16개).
- 특수 낱말(겹칠 수 있음): 빠름(1.7배 속도, +1점) 15% · 깜빡(보였다 안 보였다, +2점) 12% · 흔들(지그재그, +1점) 12% · 황금(기본 점수만큼 더) 4%.
- 협동 낱말(🤝, 참가 2명 이상일 때 약 7%): 선착순이 아니라 각자 친다. 낱말이 사라지기 전에 접속 중인 참가자 모두가 치면 모두 `기본 점수 × 배수` 를 얻고, 못 모이면 친 사람만 기본 점수를 얻는다. 배수는 속도로 정한다: 아주 천천히(낙하 시간 1.5배) 2배 · 보통 3배 · 빠름(0.7배) 4배. 다른 특수 효과는 붙지 않는다.
- 피버 타임: 경기의 45~65% 지점에서 10초. 그동안 얻는 점수는 2배이고 낱말이 더 자주 나온다(50초보다 짧은 경기는 없음).
- 안개·거꾸로: 각 8초. 안개는 화면 가운데가 가려지고, 거꾸로는 낱말이 뒤집혀 보인다. 하나는 피버 앞, 하나는 피버 뒤에 나오며 점수에는 영향이 없다.
- 역전 찬스 낱말(🚀 +4점, 2명 이상·경기 25% 이후 약 6%): 순위가 아래 30%이고 1등보다 점수가 낮은 학생에게만 보이고 그 학생만 칠 수 있다.
- 뜻 낱말(📖 +2점, 뜻풀이가 있는 낱말의 약 10%): 낱말 대신 뜻풀이가 떠다니고, 알맞은 낱말을 쳐야 득점한다.
- 팀전: 대기실에서 방장이 고른다. 들어온 순서대로 홍팀·청팀에 번갈아 들어가고, 팀 점수는 팀원 점수의 합이다. 포인트 회수는 상대 팀에게서만 가져온다. 계급 포인트는 개인 순위로 준다.
- 칭호: 결과 화면에서 속사포(낱말 수)·한 방(한 낱말 최고 점수)·선제 득점·막판 스퍼트(마지막 20초)·보너스 사냥꾼·협동왕·뜻풀이 박사·역전의 명수·피버왕·포인트 사냥꾼을 한 명씩 뽑아 보여 준다.
- 파워게이지: 오타 없이 연속 20개를 얻으면 자동으로 포인트 회수가 발동해, 그 시점 다른 참가자 각자 점수의 절반(올림)을 가져온다. 오타를 내면 게이지는 0이 되고, 한발 늦은 것은 게이지를 깎지 않는다.
- 배경음: 소리를 켠 학생에게만 경기 중에 나고, 마지막 20초에는 빨라진다.

### 6.3 점수

| 낱말 종류 | 점수 |
|---|---|
| **기본자리 글쇠만으로 된 낱말** (예: `나라`, `어머니`, `이마`) | 1점 |
| 한 단어 (예: `광합성`) | 2점 |
| 두 단어 (예: `지구 온난화`) | 4점 |

- "기본자리 낱말" 판정: 낱말의 자모열 전체가 K1 글쇠(ㅁ ㄴ ㅇ ㄹ ㅓ ㅏ ㅣ)에만 속하는 경우. 두 단어짜리여도 전부 기본자리면 2점이다.
- 점수는 모두 정수다.
- 낱말 색으로 점수를 구분해 보여 준다(1점 회색, 2점 흰색, 4점 금색).
- 동점이면 ① 획득한 낱말 수가 많은 사람 ② 마지막 득점 시각이 빠른 사람 순.

### 6.4 동기화와 선점 판정 (기술 규칙)

- 방 생성 시 `seed`(난수 씨앗)와 `startAt`(서버 시각)을 저장한다. 모든 클라이언트가 같은 `seed` 로 낱말 순서·가로 위치·등장 시각을 **똑같이 계산**한다. 낱말을 하나하나 서버로 보내지 않는다.
- 클라이언트 시계 오차는 Realtime Database 의 `.info/serverTimeOffset` 으로 보정한다.
- 선점은 `rooms/{roomId}/claims/{wordIndex}` 에 **트랜잭션**으로 쓴다. 이미 값이 있으면 실패 → "한발 늦었어요" 표시. 보안 규칙은 참가자만, 빈 칸에만, `by == 본인` 일 때 쓰기를 허용한다.
- 점수와 순위는 `claims` 를 합산해 계산한다. 모든 클라이언트가 같은 `claims` 로 같은 결과를 계산하므로 점수를 따로 저장하지 않는다.
- 접속이 끊기면(`onDisconnect`) 참가자 목록에서 빠지고, 그때까지 점수로 순위에 남는다.

### 6.5 계급과 랭킹 포인트(RP)

| 계급 | 필요 누적 RP |
|---|---|
| 훈련병 | 0 |
| 이등병 | 100 |
| 일병 | 300 |
| 상병 | 600 |
| 병장 | 1,000 |
| 예비역 | 1,500 |

```
배틀 1회 획득 RP = 5 + 2 × (참가 인원 - 내 순위)
  예) 16명 중 1등 = 35, 16명 중 16등 = 5, 2명 중 1등 = 7
조건: 경기 중 1점 이상 획득해야 RP 지급 (자리만 채우는 참가 방지)
```

- RP 는 줄지 않고 강등도 없다. 중1 학생에게 "잃는 경험"보다 "쌓는 경험"을 주기 위해서다.
- 계급이 오르면 `진급을 축하합니다! 이등병 → 일병` 창을 띄운다.
- RP 정산과 계급 변경은 경기 종료 시 클라이언트가 `claims` 로 계산해 본인 `students` 문서에 쓰고, 보안 규칙이 범위(RP 감소 불가·1회 +80 이하)를 검증한다.
- 같은 계급에 접속자가 혼자뿐이면 **연습 배틀(봇 3명)** 을 할 수 있고 RP 는 절반만 준다. → 6.6 컴퓨터 대결.

### 6.6 컴퓨터 대결 (연습 배틀)

친구가 없을 때 혼자서 컴퓨터 3명과 겨루는 연습이다. 로비의 `[🤖 컴퓨터와 대결]`(단축키 C)로 들어간다. 개방 조건은 배틀과 같다(자리연습 수료 + 교사 배틀 허용).

| 항목 | 규칙 |
|---|---|
| 진행 | 대기 없이 5초 카운트다운 → 120초. 서버 방 없이 브라우저 안에서만 진행(seed 무작위, 시각은 `performance.now`, 선점은 로컬) |
| 상대 | 컴퓨터 새내기 / 맞수 / 고수. 타수 = 기준 타수 × **0.8 / 1.0 / 1.15** |
| 낱말·점수·순위 | 친구 배틀과 같음(일정은 4명 기준 `buildSchedule`, 순위는 `rankPlayers`) |
| 보상 | RP 는 친구 배틀 공식의 **절반(내림)**, 경험치 15. 실제 배틀 전적(`games`·`wins`)에는 넣지 않음 |
| 이탈 | 경기 중 다른 화면으로 가거나 새로 고침하면 그 판은 무효(보상·수준 변화 없음) |

**기준 타수** (`engine/bots.ts` 의 `botBaseKpm`)

```
계급 추정 = 지금 계급 값 + (다음 계급 값 − 지금 계급 값) × 계급 안 진행률
           계급 값: 훈련병 90 / 이등병 120 / 일병 150 / 상병 190 / 병장 240 / 예비역 300 (영문 × 0.75)
기준 = 최고 타수가 있으면 0.7 × 최고 타수(해당 언어) + 0.3 × 계급 추정, 없으면 계급 추정
기준 × (1 + 0.04 × 컴퓨터 수준)   컴퓨터 수준 = students.solo.level (−5 ~ +10)
결과는 60 ~ 600 타, 정수
예) 훈련병 RP 0, 최고 120타 → 기준 111 → 새내기 89 / 맞수 111 / 고수 128 타
```

- 맞수는 학생과 비슷하고 고수는 조금 위다. 2등은 쉽게, 1등은 노력해야 할 수 있게 한 값이다.
- **컴퓨터 수준 조정**: 1등이면 +1(최대 10), 2등이면 유지, 3등 이하면 −1(최소 −5). `solo = { level, wins, games }` 를 결과와 같은 쓰기로 저장한다. 결과 화면에 "다음 판 컴퓨터 수준: ▲ 조금 빨라집니다 / ▼ 조금 느려집니다 / 유지" 와 컴퓨터별 타수, 격려 문구를 보여 준다.
- **컴퓨터가 치는 방식**(결정적, 시드 난수): 한 번에 낱말 하나. 화면에 있는 미선점 낱말 중 하나를 고르고(4점·2점 낱말 선호 + 무작위), 반응 400~900ms + `타수 ÷ (kpm/60)` 초 × 흔들림 0.85~1.25 뒤에 완성한다. 7% 확률로 오타가 나서 0.6초 늦어진다. 완성 전에 바닥에 닿으면 실패, 다른 사람(학생·다른 컴퓨터)이 먼저 가져가면 그 순간 포기하고 새 낱말을 고른다. 경기 중에는 계획표를 재생하지 않고 매 프레임 `createBotRunner().step(경과 시간, 선점 목록)` 으로 진행한다.

## 7. 뜻 맞추기 퀴즈 규칙

어휘력 향상용 게임이다. 낱말의 뜻풀이를 보고 맞는 낱말을 직접 쳐서 답한다. 점수는 배틀 계급(RP)과 별개로 학생의 `quizPoints`(퀴즈 누적 점수)에 쌓인다.

### 7.1 진행

| 항목 | 규칙 |
|---|---|
| 구성 | 한 판 10문제. 문제마다 뜻풀이 1개와 보기 4개(정답 1 + 오답 3)를 보여 준다 |
| 과목·언어 | 과목(국어·영어·수학·과학·사회·섞어서)과 한글/영문을 고른다. 영문은 우리말 뜻을 보고 영어 낱말을 친다. 오답 보기는 같은 과목·같은 언어 낱말에서 뽑는다 |
| 답하기 | 보기 중 정답을 입력창에 **직접 쳐서** Enter. 클릭으로 고르지 않는다(타자 연습을 겸한다). 입력값이 정답 낱말과 정확히 같으면 정답, 다르면 오답 |
| 제한 시간 | 문제당 15초. 넘기면 오답 처리. 오답이면 정답을 1초 보여 주고 다음 문제로 간다 |
| 출제 | 한 판 안에서 같은 낱말은 두 번 나오지 않는다 |
| 입력 제한 | 붙여넣기 차단 등 3.2 의 공통 금지 규칙을 따른다. 10초 무입력 일시정지는 적용하지 않는다 |

### 7.2 점수

| 항목 | 점수 |
|---|---|
| 정답 | 10점 |
| 남은 시간 보너스 | 남은 시간 3초마다 +1점, 최대 +5점 |
| 연속 정답 보너스 | 2연속째 +2, 3연속째 +4, … 최대 +10점(6연속째부터 +10 유지) |
| 오답·시간 초과 | 0점, 연속 정답은 0으로 돌아간다 |

- 점수는 모두 정수다. 한 문제 최대 25점(10 + 5 + 10), 한 판 최대 220점이다.
- 한 판의 점수 합계를 `quizPoints` 에 더한다(줄지 않는다). 기록은 `sessions` 에 `mode: 'quiz'` 로 저장하고, 경험치도 지급한다(4번 문서 3.3).
- 타수·정확도 최고 기록과 타수 순위에는 반영하지 않는다. 퀴즈 점수는 전체 순위의 "퀴즈" 탭에서만 겨룬다.
- 클라이언트가 한 판 점수를 계산해 본인 `students` 문서에 쓰고, 보안 규칙이 범위(`quizPoints` 감소 불가·1회 +220 이하)를 검증한다.

## 8. 수행평가 규칙

교사가 정한 기간에 학생이 긴 글을 정해진 시간 동안 치고, **최종 타수(타/분)로 등급**을 받는 평가다. 연습과 달리 일시정지가 없다.

| 항목 | 규칙 |
|---|---|
| 설정 | 교사가 열기/닫기, 평가 언어(한글·영어·둘 다), 제한 시간(1~10분), 언어별 최대 응시 횟수(1~5), 지문(장문 id 또는 무작위)을 정한다. `settings.exam` |
| 지문 | 지정 지문부터 시작하고, 다 치면 같은 언어의 다른 장문이 이어진다(나머지 순서는 학번을 씨앗으로 한 고정 순서). 시간이 끝날 때까지 글이 떨어지지 않는다 |
| 진행 | 시작하면 3초 카운트다운 뒤 제한 시간 동안 친다. 일시정지·가상 키보드가 없고, 창을 벗어나도 시간은 계속 흐른다. 시간이 끝나면 자동 종료 |
| 최종 타수 | 정타 수 ÷ 제한 시간(분). 중간에 멈춰 있던 시간도 제한 시간에 포함한다 |
| 응시 횟수 | 시작하는 순간 먼저 +1 로 저장한다(새로 고침으로 되돌릴 수 없다). 다 쓰면 응시할 수 없다 |
| 인정 기록 | 언어별로 가장 높은 타수 기록이 인정된다. 타수가 기존보다 높을 때만 등급·타수·정확도·오타를 바꾼다 |
| 기록 | 응시가 끝나면 `sessions` 에 `mode: 'exam'` 으로 저장하고 `students.exam` 을 갱신한다. 타수·정확도 최고 기록과 순위에는 반영하지 않는다 |

등급표(1분 평균 타수)

| 등급 | 한글 | 영어 |
|---|---|---|
| A | 200타 이상 | 150타 이상 |
| B | 170~199타 | 130~149타 |
| C | 140~169타 | 110~129타 |
| D | 110~139타 | 90~109타 |
| E | 110타 미만 | 90타 미만 |

- 교사는 학생별(또는 반별) 결과를 초기화해 다시 응시하게 할 수 있고, 결과를 CSV 로 내보낸다.

## 9. 전체 순위

| 순위표 | 정렬 기준 | 범위 필터 |
|---|---|---|
| 배틀 순위 | 누적 RP (같으면 배틀 승수) | 전체 / 반별 / 계급별 |
| 퀴즈 순위 | 누적 퀴즈 점수(`quizPoints`) | 전체 / 반별 |
| 한글 타수 순위 | 단문·장문 최고 타수 (정확도 90% 이상 기록만) | 전체 / 반별 |
| 영문 타수 순위 | 같음 | 전체 / 반별 |
| 성실 순위 | 누적 연습 일수 → 누적 연습 시간 | 전체 / 반별 |
| 이번 주 성장 순위 | 지난주 대비 타수 증가량 | 전체 / 반별 |

- 순위표는 `students` 를 직접 읽어 만든다(로그인한 학생·교사만 읽기 가능).
- 순위표에는 `반 + 이름 + 계급`만 표시한다(예: `3반 김민수 · 일병`). 학번은 화면에 노출하지 않는다.
- 내 순위는 항상 맨 위에 고정해 보여 준다.

## 10. 부정 방지와 보안 규칙 검증

서버 함수·Firebase Admin·맞춤 토큰은 쓰지 않는다. 서비스 계정 키를 관리하지 않아도 되도록 권한은 Firestore·Realtime Database 보안 규칙만으로 강제한다.

| 위험 | 대응 |
|---|---|
| 붙여넣기·매크로 | paste 차단, 1,500타/분 초과 무효, 글쇠 간격이 20ms 미만으로 10회 연속이면 무효 |
| 개발자 도구로 기록 조작 | 보안 규칙에서 본인 문서 쓰기를 제한: 이름·학번 불변, RP 감소 불가·1회 +80 이하, 자리 단계 감소 불가·1회 +1 이하, 퀴즈 점수 감소 불가·1회 +220 이하, 타수 0~1500 |
| 친구 계정 도용 | PIN 4자리. 학생은 익명 로그인 후 `links/{uid}`(`sid, name, pinHash`)를 만들어 자신을 증명하고, 규칙이 `students/{sid}` 의 이름과 `secrets/{sid}` 의 PIN 해시(SHA-256, 클라이언트 읽기 불가)가 일치할 때만 생성을 허용 |
| 배틀 자리 채우기 | 1점 이상 획득해야 RP 지급 |

PIN 은 첫 접속 때 학생이 정한다(로그인 화면의 "처음 접속" 선택). PIN 초기화는 교사가 `secrets/{sid}` 를 지우는 것이다.

알려진 한계

- PIN 5회 실패 잠금은 구현하지 않는다(보안 규칙만으로는 실패 횟수를 셀 수 없다).
- 4자리 PIN 은 무차별 대입에 약하므로 수업용 수준의 보호다.
- 개발자 도구를 쓰는 학생은 규칙이 허용하는 범위 안에서 자기 기록을 부풀릴 수 있다.

## 11. 미확정 사항 (작업 개시 전 확인)

1. 승급 테스트 문항 제한 시간 3초가 중1 초보자에게 적당한지 → 첫 수업 후 조정 가능하도록 교사 설정값으로 둔다.
2. 계급 RP 기준(100/300/600/1000/1500)은 한 학기(약 17주, 주 1~2회 배틀) 기준 추정값이다. 운영하며 조정할 수 있게 설정값으로 둔다.
